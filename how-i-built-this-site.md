  <h1 id="build-heading">How I built this site</h1>
  <p class="article-meta">Tool stack, layout decisions, and workflow notes</p>

  <p>
    This project uses Jekyll for static-site generation, GitHub Pages for hosting, and a GitHub Actions workflow to build and deploy on every commit to <code>main</code>.
    The layout uses reusable includes and a consistent page structure so each theory lens can be edited independently.
  </p>
  <p>
    The current version was scaffolded with assistance from an AI coding agent, which set up structure, styling, accessibility markers, and starter text.
    Final arguments, examples, and scholarly analysis are authored by you.
  </p>
